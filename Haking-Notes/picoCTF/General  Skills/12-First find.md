## Descripción 
Unzip this archive and find the file named 'uber-secret.txt'
		Download zip file
## Solución

Este caso tiene la misma solucion que el 11-Big zip, primero de descomprimio el archivo file.zip

```bash
unzip file.zip
```

Una vez ya descomprimido lo que se hizo fue que con grep y -r se busco sobre todos los archvos

```bash
grep -r "pico"
```

lo cual busco sobre todo el directorio y subdirectorios existentes hasta encontrar la siguiente similutud con la palabra a buscar 

```
picoCTF{f1nd_15_f457_ab443fd1}

```
