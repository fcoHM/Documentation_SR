## Descripción 
What is 0x3D (base 16) in decimal (base 10)?
## Solución
Para este caso se uso una funcion muy basica de python, que en este caso fue lasiguiente

```Python
valor = 0x3D
resultado = int(valor)
print(resultado)
```

dando como resultado
```
picoCT{61}
```
