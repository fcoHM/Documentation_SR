## Descripción 
This .tar file got tarred a lot.
## Solución
se nos otorga un tar "1000.tar" que en su interior tiene un carepeta 999.tar y asi 1000 veces
- elaboramos un script para desenpaquetar
```bash
for i in {1000..1}; do tar -xvf $i.tar; done
```
- esto lo que hace es automatizar el desenpaquetado esto aplicando el tar -xvf para todos los archivos con los valores decresientes .tar
- vemos que depues de desenpaquetar hay un archivo falg.png
```
picoCTF{l0t5_0f_TAR5}
```
## Notas adicionales
se pudo haber resuelto en python 

```python
import tarfile
for i in range(1000, 0,-1):
	archivo = "{}.tar".format(i)
	print(archivo)
	tar = tarfile.open(archivo)
	tar.extractall()
	tar.close()
	
```
